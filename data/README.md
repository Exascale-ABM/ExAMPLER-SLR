# data

The following are results data from the SLR that can be shared:

  + `ExAMPLER SLR form.csv` -- Results from the review process, as downloaded from the Google Form that implemented it.
  + `dodgy-dois.csv` -- DOIs suspected by the automated merge process to be duplicates
  + `dodgy-dois.csv-metadata.json` -- [W3C recommended](https://www.w3.org/TR/tabular-data-primer/) metadata file to accompany `dodgy-dois.csv`
  + `merge-param.tex` -- [LaTeX](https://www.latex-project.org/) format table detailing parameters used during the merge process
  + `merge-table.tex` -- [LaTeX](https://www.latex-project.org/) format table with results from merge
  + `slr-screening-results-users.json` -- [JSON](https://www.json.org/) format results from the screening form
